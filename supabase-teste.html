Teste da integração com o Supabase

Esta página confere, do próprio navegador, se os diagnósticos preenchidos no site estão chegando ao Supabase: se as chaves do projeto estão corretas, se a tabela diagnosticos existe com as colunas atuais e se o bucket relatorios aceita o envio dos arquivos. É uma página de uso interno, sem link no menu do site.

O envio de teste grava uma linha chamada “TESTE — pode apagar” na tabela e um arquivo em _teste/ no bucket. É o único jeito de provar que a gravação funciona de ponta a ponta. Depois é só apagar os dois pelo painel do Supabase.

Se algo estiver vermelho

  1. Abra o painel do Supabase, vá em SQL Editor > New query, cole todo o conteúdo do arquivo supabase-setup.sql deste repositório e clique em Run. O script pode ser rodado quantas vezes for preciso, sem apagar nada do que já foi gravado.
  2. Confira em Settings > API se a Project URL e a chave anon public são as mesmas que estão no topo do arquivo supabase-config.js.
  3. Se o bucket não aparecer, crie-o à mão em Storage > New bucket, com o nome relatorios e a opção Public desmarcada. Depois rode o script de novo.
  4. Volte aqui e clique em Verificar de novo.

Onde ver os diagnósticos recebidos

As respostas ficam em Table Editor > diagnosticos, uma linha por diagnóstico finalizado, com nome, e-mail, score, arquétipo e o resumo do plano de aposentadoria (patrimônio necessário, aporte necessário e aporte atual). A coluna respostas guarda o formulário inteiro e relatorio_arquivo diz qual arquivo do bucket corresponde àquela linha.

Os relatórios ficam em Storage > relatorios, em HTML, prontos para abrir no navegador ou imprimir em PDF. O bucket é privado: só quem entra no painel com a sua conta consegue baixar.
