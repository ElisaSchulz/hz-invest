Planilha de Orçamento

Organize suas receitas e despesas mensais, visualize onde vai cada real e exporte para Excel quando quiser.

Como usar a planilha

Clique para ver o passo a passo completo

1
Selecione o mês que deseja planejar no menu abaixo. Cada mês é salvo separadamente no seu navegador.
2
Preencha seus rendimentos (salário, freelas, etc.) e suas despesas por categoria. Clique no nome de qualquer item para editar, e use o botão + para adicionar linhas.
3
A coluna Previsto é o que você planeja gastar. A coluna Real é o que efetivamente gastou. Compare os dois para entender seus desvios.
4
Clique em Exportar Excel para baixar um arquivo .xlsx pronto para abrir no Excel ou Google Sheets. Clique em Exportar PDF para imprimir ou salvar como PDF.
5
Os dados ficam salvos no seu navegador. Se limpar o histórico do navegador, os dados podem ser perdidos, então exporte periodicamente para não perder nada.
